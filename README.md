# Portfólio profissional de Andressa Lima

Site estático de uma página com apresentação profissional, produtos selecionados, experiência, habilidades e contato.

## Executar localmente

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`.

## Publicação

O projeto pode ser publicado diretamente pelo GitHub Pages a partir da branch principal.
